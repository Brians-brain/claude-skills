# 致謝

**摘要**段落中的視覺呈現選單（虛擬碼、呼叫樹、元件樹、檔案樹、Mermaid、diff）及其擺放指引，來自 [Dex Horthy](https://github.com/dexhorthy) 的 [`show-me`](https://github.com/humanlayer/humanlayer) skill，原 skill 幾乎逐字收錄，只是把對象從即時對話改成 diff。`pr` 並不以 skill 的形式依賴 `show-me`（它不屬於這個 repo，硬性依賴會讓單獨安裝失效），所以內容是複製進來而不是用指標引用；這個檔案就是原本依賴關係會帶有的致謝。本 repo 版本另外翻譯為繁體中文，並把範例改為 Python 與 BOM 成本情境。
