---

開一個**背景 agent** 去做研究，讓你可以繼續工作，同時它在閱讀。

給它的任務：

1. 從**一手來源**調查這個問題（官方文件、原始碼、規格書、原廠 datasheet、第一方 API 文件），而不是別人寫的二手整理。每一個論點都要追溯到擁有它的原始來源。
2. 把調查結果寫成單一 Markdown 檔，以繁體中文撰寫，每一個論點都附上來源連結；API 欄位名稱、參數、程式碼維持原文。
3. 存放在 repo 既有存放這類筆記的位置，沿用既有慣例；如果沒有慣例，就放在合理的地方（例如 `docs/research/`），並告訴使用者存在哪裡。
