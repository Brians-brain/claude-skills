# Triage 標籤

這些 skill 以五種標準 triage 角色來描述狀態。這個檔案把這些角色對應到這個 repo 的 issue tracker 實際使用的標籤字串。

| mattpocock/skills 中的標籤 | 我們 tracker 中的標籤 | 意義 |
| -------------------------- | -------------------- | ---------------------------------------- |
| `needs-triage`             | `needs-triage`       | 維護者需要評估這個 issue |
| `needs-info`               | `needs-info`         | 等待回報者提供更多資訊 |
| `ready-for-agent`          | `ready-for-agent`    | 已完整定義，可交給無人看管的 agent |
| `ready-for-human`          | `ready-for-human`    | 需要由人實作 |
| `wontfix`                  | `wontfix`            | 不會處理 |

當 skill 提到某個角色時（例如「套用可交給 agent 的 triage 標籤」），使用這張表中對應的標籤字串。

修改「我們 tracker 中的標籤」這一欄，讓它符合你實際使用的用語。
