# GLOSSARY.md 格式

`GLOSSARY.md` 是這個教學工作區的標準用語。所有講解、練習與學習紀錄都應該遵守它的術語。建立術語表本身就是學習的一部分：能把一個概念壓縮成精確的定義，就是使用者理解它的證據。

## 結構

```md
# {主題} 術語表

{一到兩句話說明這份術語表涵蓋的主題。}

## 術語

**解析頻寬（RBW, Resolution Bandwidth）**：
頻譜分析儀中頻濾波器的頻寬，決定儀器能分辨兩個相鄰訊號的最小頻率間隔。
_避免使用_：解析度、濾波器寬度

**顯示平均雜訊位準（DANL）**：
在指定 RBW 下、無輸入訊號時，頻譜分析儀顯示的雜訊底線位準。
_避免使用_：底噪、雜訊地板（未說明 RBW 時）

**S21**：
雙埠網路中，從埠 1 輸入、在埠 2 量到的傳輸係數。
_避免使用_：增益、穿透量（未說明方向時）
```

## 規則

- **只有使用者理解了才加入術語。** 術語表是壓縮知識的紀錄，不是讓使用者拿來學習的字典。如果使用者剛接觸一個概念，要等到他能正確使用它，才把它收進來。
- **要有主見。** 同一個概念有多種說法時，選最好的一個，其餘列為避免使用的別名。語言就是這樣被壓縮的。
- **定義要精簡。** 一到兩句。定義這個術語**是什麼**，而不是它做什麼或怎麼做。
- **定義中使用術語表自己的術語。** 一旦某個術語進了術語表，到處都優先用它，包括其他術語的定義裡。這會讓複雜的術語之後更容易理解。
- **自然形成群組時，用子標題分組**（例如 `## 頻譜分析`、`## 網路分析`）。術語內聚時，平鋪一個清單即可。
- **明確標出歧義。** 如果某個術語在業界用得很鬆散，註明本工作區的用法：「在本工作區，『功率』一律指平均功率；峰值功率另外標示。」
- **隨理解加深而修正。** 使用者第一週寫的定義，到第六週可能是錯的。直接原地更新，不要留下過時的條目。
