# 學習紀錄格式

學習紀錄放在 `./learning-records/`，依序編號：`0001-slug.md`、`0002-slug.md`，依此類推。目錄採延遲建立：寫第一筆紀錄時才建立。

它們是教學版的 ADR：記錄不明顯的心得、關鍵洞見，以及使用者自述的先備知識，這些會引導之後的 session。它們用來推算近側發展區。

## 範本

```md
# {學到了什麼或確立了什麼的簡短標題}

{1–3 句話：學到了什麼（或確立了哪些先備知識），以及它對之後的 session 為什麼重要。}
```

這就是完整格式。一筆學習紀錄可以只有一段話。它的價值在於記錄「**這件事現在已經會了**」以及「**它為什麼改變接下來要教的東西**」，而不是把各個欄位填滿。

## 選用段落

只有在真正有價值時才加。大多數紀錄用不到。

- **Status** frontmatter（`active | superseded by LR-NNNN`）：當早先的理解被證明錯誤並被取代時有用。
- **證據**：使用者如何展現他的理解（回答了某個問題、完成了某個練習、引用了過去的經驗）。當這個論點之後可能被重新檢視時有用。
- **影響**：這件事為之後的 session 解鎖了什麼、或排除了什麼。不明顯時值得記錄。

## 編號

掃描 `./learning-records/` 找出目前最大的編號，加一。

## 什麼時候寫學習紀錄

以下任何一項成立時就寫：

1. **使用者對某個不簡單的東西展現了真正的理解**：不只是接觸過，而是有證據顯示他能正確使用這個概念。這為接下來要教的內容設定了新的底線。
2. **使用者揭露了先備知識**：「我已經會 X 了。」記下來，免得之後的 session 重教一次。也要記下他自稱的**深度**。
3. **一個錯誤觀念被修正了**：使用者之前相信某件錯的事，現在明白為什麼錯。這類紀錄價值很高：它們能預測相關主題上未來的絆腳石。
4. **任務因為學習而改變了**：使用者發現自己在意的東西跟原本以為的不同。交叉連結到 [[MISSION.md]] 並更新它。

### 不算數的情況

- 只是被講過的內容。講過不等於學會，要等到有證據。
- 已經以術語定義的形式精簡記在 [[GLOSSARY.md]] 裡的東西。不要重複。
- 逐次 session 的活動紀錄。學習紀錄不是日記，而是足以作為決策依據的洞見。

## 取代

當後來的紀錄與先前的紀錄矛盾時（使用者的理解加深或被修正），把舊紀錄標記為 `Status: superseded by LR-NNNN`，而不是刪除它。理解如何演變的歷史本身就是有用的訊號。
