# RESOURCES.md 格式

`RESOURCES.md` 是這個主題精選的可信來源清單。課程中的知識應該取自這裡，而不是憑記憶猜測。智慧則來自這裡列出的社群。

## 結構

```md
# {主題} 資源

## 知識

- [應用筆記：Keysight AN 150《Spectrum Analysis Basics》](https://example.com)
  頻譜分析儀原理的基礎讀物。用於：RBW、VBW、掃描時間、雜訊底線相關的任何問題。
- [書：《Microwave Engineering》by David M. Pozar](https://example.com)
  傳輸線與網路參數的標準教科書。用於：S 參數、阻抗匹配、Smith 圖的推導。

## 智慧（社群）

- [EEVblog 論壇 RF 版](https://example.com)
  實務工程師聚集、討論品質高。用於：量測設定的實務問題、儀器選擇。
- 在地：{原廠} 的量測研討會
  用於：在儀器前直接得到即時指導。
```

## 規則

- **只收高可信度來源。** 優先選擇一手來源、公認的專家、經同儕審查的著作，以及有嚴格管理的社群。包裝成教育的行銷內容不要收。
- **每一筆都要附註。** 三個月後，光禿禿的連結毫無用處。加一行說明：它涵蓋什麼、什麼時候該去查它。
- **依「知識／智慧」分組。** 對應 [SKILL.md](./SKILL.md) 的教學理念。一個資源只出現在其中一組是正常的。
- **明確標出缺口。** 如果任務需要的某個領域找不到好資源，寫一個 `## 缺口` 段落列出缺少什麼，用來驅動之後的搜尋。
- **無情地修剪。** 被證明錯誤、膚淺或偏離任務的資源應該移除，而不是埋在清單裡。五個精準的來源勝過三十個平庸的。
- **記錄社群偏好。** 如果使用者選擇不加入社群，在這裡記下來，免得之後的 session 一直提議。
